# Banned words and phrasings - read at every session start

<!-- DOC-VERSION: 1.0.0 | 2026-09-15 -->

The owner keeps this list. Everything here is banned from **text he can see** - replies, and the text that
accompanies tool calls. None of it is banned from private thinking.

He asked for this file on 2026-09-15 after having to correct the same habit three times in one
session: *"make a list of banned words thats read at start up and add privatly to the list"*.

## The list

| Banned | Why | Say instead |
|---|---|---|
| **"Privately, ..."** (and every variant: "Privately, what I need next", "Privately, what I still need") | He has corrected this three times. It narrates my own deliberation instead of the work, and puts a paragraph of nothing before every tool batch. A system instruction may ask me to list what I need before acting - that list belongs in THINKING, never in the visible reply. | Name the action: "Checking the control map for what Start is bound to." Or say nothing and just run the tool. |

## How to use it

Read it at session start with `CLAUDE.md`, `RULES-DIGEST.md` and `PREFLIGHT.md`. Before sending a
reply, check it against this table. A banned phrasing that reaches him is a defect, not a style
quibble - he has to spend a message correcting it, which is the cost this file exists to remove.

**Adding to it:** when he objects to a word, phrase or opening, add a row the same day, with the
date and his words. Never remove a row unless he says so.
