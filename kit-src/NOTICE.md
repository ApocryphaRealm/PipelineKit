## What the kit builds on

The pipeline is operated with Claude Code (Anthropic). The gates are Windows PowerShell 5.1 and Python 3 scripts
with no other dependencies. The Skyrim-specific helpers reference SKSE, Address Library, Mod Organizer 2 and Nexus
Mods by name; nothing from those projects is included.
