Example Mod
===========
Version 1.0.0

The Pipeline Kit's example mod: a Mod Organizer 2 plugin with one toolbar button that shows a hello dialog. It
exists so the kit's self-test can carry a real package through every stage - identity, an issued number, a
changelog entry, the package gate, an earned "working", the finalize gate - without a compiler.

THIS IS NOT A MOD. Do not install it with the mod manager.

INSTALLATION (if you want to see it run)
----------------------------------------
Copy plugins\example_mod.py into your Mod Organizer 2 "plugins" folder and restart MO2.

WHAT CHANGED IN 1.0.0
---------------------
Version 1.0.0
Added one toolbar button that says hello.
